# Changelog fragments

Each change that users notice adds one file here instead of editing `CHANGELOG.md`, so open
branches never conflict on the changelog.

- Name: `<short-slug>.<type>.md`, where `<type>` is `added`, `changed`, `fixed` or `removed`.
- Content: one or more Markdown bullets, written for users.
- At release, the fragments are folded into `CHANGELOG.md` under the new version and deleted.
